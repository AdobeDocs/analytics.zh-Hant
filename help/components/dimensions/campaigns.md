# 行銷活動

「行銷活動」 [維度](overview.md)可以指：

* 某些報表套裝中自動建立的[分類](../classifications/classifications-overview.md)。 其基礎為[追蹤代碼](tracking-code.md)維度。
* [追蹤代碼](tracking-code.md)維度本身，此維度會使用[行銷活動](/help/implement/vars/page-vars/campaign.md)實施作業變數。
