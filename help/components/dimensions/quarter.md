# 季

「季」[維度](overview.md)會報告指定量度發生的季。 第一個維度項目是日期範圍中的第一季，最後一個維度項目是日期範圍中的最後一季。 此維度可讓您查看量度在一段時間內變化，因此非常適合用於趨勢報表。

## 將資料填入此維度中

此維度衍生自每次點選的時間戳記。 沒有變數可供設定；其可直接用於任何實施作業。

| 屬性 | 價值 |
| --- | --- |
| **AppMeasurement變數** | 無（衍生自點選時間戳記） |
| **網頁SDK / XDM欄位** | 無（衍生自點選時間戳記） |
| **查詢引數** | 不適用 |
| **XML標籤** | 不適用 |
| **位元組限制** | 不適用 |
| **持續性** | 點擊 |

## 維度項目

維度項目包含指定日期所屬的季度 (3 個月) 和年份。
