# 網頁SDK移轉規劃工具

網頁SDK移轉規劃工具可協助您規劃及執行將Adobe Analytics標籤擴充功能移轉到Adobe Experience Platform網頁SDK的程式。 其將移轉帶入Adobe Experience Platform資料收集內的單一引導式工作區，因此您可以採用結構化、可追蹤的方式，從現有的標籤實作移至Web SDK。

>[!AVAILABILITY]
>
>工具和檔案都在積極開發中。 檔案可用性預計於2026年9月底推出。
